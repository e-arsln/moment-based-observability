# moment-based-observability
A Python example for constructing observability Gramians for ODE dynamics with parametric polynomial output  transformations. The Jupyter notebook computes the observability Gramians for a two-dimensional system and outputs  plots of the minimum eigenvalues and the log-determinant of this Gramian on the grid of two parameters of the output transformation.

Dependencies: NumPy, Matplotlib, Jupyter Notebook
